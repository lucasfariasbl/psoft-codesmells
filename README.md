# Code Smells
Atividade do curso de Projeto de Software

## Objetivo
Identificar 3 tipos de code smells em projetos open-source ou desenvolver código Java que apresente esses problemas, realizando os refactorings necessários para corrigi-los.

---
### 1. Duplicated Code
Ocorre quando o mesmo trecho de código, ou uma lógica muito semelhante, existe em dois ou mais lugares diferentes do projeto.

### 2. Shotgun Surgery
Acontece quando uma única alteração conceitual no sistema exige que você faça pequenas modificações em muitas classes ou arquivos diferentes ao mesmo tempo.

### 3. Lazy Class/Function
Refere-se a uma classe ou função que não faz o suficiente para justificar sua própria existência e manutenção.
